# Contributing

Start with [HUMANS.md](HUMANS.md), [TASKS.md](TASKS.md), and [ARCHITECTURE.md](ARCHITECTURE.md). AI coding assistants must also read [AGENTS.md](AGENTS.md).

Keep contributions within the [current scope](docs/SCOPE.md), preserve SRS compatibility, and include appropriate [verification](docs/TESTING.md). Document copied or translated material in [NOTICE.md](NOTICE.md).

Run `python3 scripts/check.py` before submitting code. Use the pull request template and state all pending platform or listening checks. Do not send recordings, secrets, or private server captures with a public report.
